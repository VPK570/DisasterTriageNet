## 10. Phase 2: Prior Art Search - Novelty Analysis

### Search Queries (Google Patents)

#### Query 1: "triage" + "dispatch" + "real-time re-optimization"

**Results:**
- US7624024B2 - Systems and methods for dynamically updating a dispatch plan (UPS, delivery logistics - NOT emergency/medical)
- US20110040595A1 - Real-time service management and dispatch system (aircraft services)
- US20130030825A1 - Systems and methods for automated triage and scheduling in an emergency department (triage only, no dispatch re-optimization)

**Finding:** No patents specifically coupling emergency triage re-scoring with dispatch re-optimization.

---

#### Query 2: "dynamic triage" + "ambulance routing" + "feedback"

**Results:**
- Scientific paper: "Ambulance route optimization in a mobile ambulance dispatch system using deep neural network (DNN)" - 2025 (academic, not patent)
- US20170344707A1 - Integrated ambulance tracking system (tracking, not dynamic triage feedback)
- US11908581B2 - Patient risk assessment based on data from multiple sources (hospital risk, not pre-hospital triage)
- Academic: "Online algorithms for ambulance routing in disaster response with time-varying victim conditions" - 2024 OR Spectrum (research paper)

**Finding:** No patents found that implement a feedback loop between dynamic triage re-scoring and ambulance routing re-optimization.

---

#### Query 3: "mass casualty" + "continuous scoring" + "resource allocation"

**Results:**
- US7761309B2 - Method and system of mass and multiple casualty triage (static triage, resource-constrained optimization but NO continuous re-scoring)
- US6761312B2 - System and method for tracking victims of a mass casualty incident (tracking, not continuous scoring)
- US10861320B2 - Predictive analytics for emergency detection and response management (predictive, not continuous re-scoring)
- Academic: "ABMS-Driven Reinforcement Learning for Dynamic Resource Allocation in Mass Casualty Incidents" - 2025 (RL + optimization, research paper)
- Academic: "DeepTriage: A Real-Time AI Decision Support System for Emergency Resource Allocation in Mass Casualty Incidents" - 2025 (AI decision support, research paper)

**Finding:** No patents covering continuous/real-time triage re-scoring with dynamic resource re-allocation.

---

### Key Findings: Novelty Argument

**FREEDOM-TO-OPERATE CONFIRMATION:**

| Claim | Existing Prior Art | Gap |
|-------|-------------------|-----|
| Dynamic triage re-scoring | US20130030825A1 (one-time dynamic triage in ED) | No continuous re-scoring during incident |
| Dispatch re-optimization | US7624024B2 (delivery logistics), US20170344707A1 (ambulance tracking) | No coupling to triage changes |
| Feedback loop (triage → dispatch) | None found | NO PATENT COVERS THIS |
| Continuous scoring + resource re-allocation | US7761309B2 (static optimization) | No real-time continuous scoring |

**Novelty Argument:**
No existing patent specifically combines:
1. **Dynamic triage re-scoring** based on time-decay and vital sign changes
2. **Real-time dispatch re-optimization** triggered by triage changes
3. **Bidirectional feedback loop** between victim condition changes and ambulance routing adjustments
4. **Severity-weighted clustering** that updates as victims deteriorate/improve

This combination represents a novel contribution that is not covered by any existing patent in the search results.
